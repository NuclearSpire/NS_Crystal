# Crysal Character Mod

This is the source code for the Crystal Character Mod, apart of the Nuclear Spire collection for Slay the Spire 2.

## Character Design

Crystal is a defensive powerhouse who turns her armor into a weapon.

Inpired by Nuclear Throne's Crystal, she is not meant to be a passive tank who simply blocks forever. Her identity is built around the cycle of:

> Build your crystal shell → Survive impossible attacks → Shatter it for power → Fight exposed → Rebuild

Her strength comes from controlling when she is protected and when she is vulnerable.
